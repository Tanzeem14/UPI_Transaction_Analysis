# 📊 UPI Transactions Dashboard Analysis

An interactive **Power BI dashboard** that analyzes UPI transaction patterns across India, covering UPI applications, banks, states, transaction types, transaction status, devices, merchant categories, and transaction timing.

The project analyzes **125,406 UPI transactions** recorded between **January 2024 and July 2024** using Microsoft Power BI.

---

## 📌 Project Overview

The **UPI Transactions Dashboard Analysis** provides a data-driven view of India's digital payment ecosystem.

The dashboard was developed using **Microsoft Power BI** to analyze transaction volume, transaction value, UPI application distribution, banking infrastructure, geographic performance, transaction types, transaction timing, transaction success, cashback, and flagged transactions.

The analysis covers **125,406 transactions across India** for the period **January–July 2024**.

---

## 🎯 Project Objective

The primary objective of this project is to analyze UPI transaction patterns across:

- UPI applications
- Banks
- States
- Transaction types
- Transaction status
- Time periods
- Device types
- Merchant categories
- Flagged transactions

### Key Questions

The dashboard addresses questions such as:

- Which UPI apps have the highest transaction share?
- Which banks process the highest transaction amount?
- Which states contribute the most transaction value?
- Which transaction types dominate?
- When is UPI activity highest?
- What is the transaction success rate?
- What patterns appear in flagged transactions?
